ABOUT SHOPNOVA

Shopping meets
DevOps.

ShopNova is a modern e-commerce project designed to demonstrate how a frontend application can be developed, tested, automated and deployed using DevOps practices.

OUR STORY

Built as a bridge between development and operations.

ShopNova combines a simple shopping experience with DevOps concepts such as version control, automation, continuous integration, continuous deployment, containers and cloud infrastructure.

The project is intentionally built with plain HTML, CSS and JavaScript so it can be easily deployed to platforms such as Nginx, Apache, Docker or cloud static hosting services.
